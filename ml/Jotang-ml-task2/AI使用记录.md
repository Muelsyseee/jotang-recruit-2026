# AI 使用记录

本项目在学习、实践和仓库整理过程中使用了 AI，主要用途如下：

1. **回答问题，辅助理解概念**：通过提问与追问，辅助理解图像处理、卷积、卷积神经网络、数据增强等相关概念。
2. **查询函数用法**：辅助了解相关函数的作用、参数含义、输入输出及使用示例。
3. **提供代码与模型结构参考**：提供代码示例和模型结构参考，辅助理解实现思路与网络中各层的作用。
4. **审查 note 中的回答**：辅助检查 `note.md` 中的概念表述、回答与代码的一致性，以及文件链接和路径。
5. **代码 debug**：辅助检查 Python 和 Jupyter Notebook 代码，重点排查变量定义、单元格执行依赖、文件路径及函数调用等问题，并协助修正已确认的问题。
6. **整理文件**：辅助梳理仓库文件夹结构、核对文件位置与引用路径，并清理已确认的空图片文件。
7. **辅助撰写 README**：根据项目实际目录及阅读方式，整理文件夹结构、代码与回答的位置、模型文件说明和依赖包信息。
